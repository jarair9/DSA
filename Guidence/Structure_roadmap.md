
# DSA Roadmap (Interview-Oriented)

## Phase 1: Foundations (1–2 Weeks)

* Time & Space Complexity

  * Big O
  * Big Ω (Omega)
  * Big Θ (Theta)
* Complexity analysis of your own code
* Basic mathematics

  * Number theory fundamentals
  * GCD & LCM
  * Prime numbers
* Bit manipulation fundamentals

---

## Phase 2: Arrays & Strings (2–3 Weeks)

Master the most common interview patterns.

### Core Concepts

* Arrays
* Strings

### Patterns

* Two Pointers
* Sliding Window
* Prefix Sum
* Difference Array (optional)

---

## Phase 3: Hash Maps & Sorting (2 Weeks)

### Hash-Based Data Structures

* Hash Map
* Hash Set
* Frequency counting
* Counting techniques

### Sorting

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort
* Counting Sort
* Radix Sort (optional)

Learn when sorting simplifies a problem.

---

## Phase 4: Binary Search & Intervals (2 Weeks)

### Binary Search

* Classic Binary Search
* Lower Bound
* Upper Bound
* Binary Search on Answer
* Rotated Sorted Array
* Peak Element

### Interval Problems

* Merge Intervals
* Insert Interval
* Meeting Rooms
* Non-overlapping Intervals

---

## Phase 5: Linear Data Structures (2–3 Weeks)

### Linked Lists

* Singly Linked List
* Doubly Linked List
* Circular Linked List
* Fast & Slow Pointers (Floyd's Cycle Detection)

### Stacks

* Stack implementation
* Monotonic Stack
* Expression evaluation

### Queues

* Queue
* Circular Queue
* Deque
* Priority Queue basics

---

## Phase 6: Recursion & Backtracking (2 Weeks)

### Recursion

* Base cases
* Recursion tree
* Call stack
* Divide and Conquer

### Backtracking

* Subsets
* Permutations
* Combination Sum
* N-Queens
* Sudoku Solver

A strong understanding of recursion is essential before moving on to Trees, Graphs, and Dynamic Programming.

---

## Phase 7: Trees & Heaps (3 Weeks)

### Trees

* Binary Trees
* Binary Search Trees (BST)
* Tree Traversals

  * Inorder
  * Preorder
  * Postorder
  * Level Order
* DFS
* BFS

### Heaps

* Min Heap
* Max Heap
* Heapify
* Priority Queue
* Top-K Problems

### Tries

* Prefix Trees
* Autocomplete
* Dictionary Problems

---

## Phase 8: Graphs (3 Weeks)

### Graph Fundamentals

* Adjacency List
* Adjacency Matrix

### Traversal

* DFS
* BFS

### Graph Algorithms

* Topological Sort
* Union-Find (Disjoint Set Union)
* Cycle Detection
* Bipartite Graph
* Connected Components

---

## Phase 9: Greedy Algorithms (1–2 Weeks)

* Activity Selection
* Interval Scheduling
* Huffman Coding
* Gas Station
* Jump Game
* Fractional Knapsack

---

## Phase 10: Dynamic Programming (4–5 Weeks)

### DP Fundamentals

* Memoization
* Tabulation

### 1D DP

* Fibonacci
* Climbing Stairs
* House Robber

### 2D DP

* Grid Paths
* Edit Distance
* Longest Common Subsequence

### Knapsack Patterns

* 0/1 Knapsack
* Unbounded Knapsack

### Advanced DP

* DP on Trees
* DP on Graphs (optional)

---

## Phase 11: Advanced Graph Algorithms (2 Weeks)

* Dijkstra's Algorithm
* Bellman-Ford Algorithm
* Floyd-Warshall (optional)
* Minimum Spanning Tree

  * Kruskal's Algorithm
  * Prim's Algorithm

---

## Phase 12: Practice & Interview Preparation (Ongoing)

Practice by **patterns**, not randomly.

### Essential Patterns

* Two Pointers
* Sliding Window
* Prefix Sum
* Hash Map
* Binary Search
* Intervals
* Fast & Slow Pointers
* Monotonic Stack
* Tree DFS/BFS
* Graph DFS/BFS
* Top-K Elements
* Backtracking
* Greedy
* Dynamic Programming

Recommended problem lists:

* NeetCode 150
* Blind 75
* Grind 169 (optional)

Aim to solve **150–250 high-quality problems** rather than hundreds of random ones.

---

# Practical Tips

* Implement every major data structure from scratch at least once before relying on Python's built-in libraries.
* Learn to recognize **problem patterns** rather than memorizing solutions.
* Review previous topics regularly to avoid forgetting them.
* Don't move to Dynamic Programming until recursion feels natural.
* Spend most of your time on Arrays, Hash Maps, Binary Search, Trees, Graphs, and Dynamic Programming, as these dominate coding interviews.
